# UXcel Figma-inspired prototype

This is a responsive HTML/CSS/JavaScript prototype recreated from the photos of your Figma frames.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge, or open the folder in VS Code.
3. On mobile, it fills the screen like an app. On laptop, it shows a centered phone prototype plus screen navigation controls.
4. Use the prototype flow buttons on desktop to jump to any screen. On mobile, scroll below the app to find those controls.

## Screens included
- Splash screen
- Sign in / welcome
- Signup with email
- Password entry with live password requirements
- Password entered / completed state
- Onboarding with learning preferences
- Welcome completion screen

## Notes
The photo shows the first five screens clearly, while the onboarding and welcome screens are only partly visible. Those two screens are approximations based on the visible layout and can be adjusted if you share more details. This is a front-end prototype only: no real account, backend, Google, Apple, Facebook, or SSO authentication is connected. Do not use a real password in the demo.
